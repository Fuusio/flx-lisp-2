# Changelog

All notable changes to the FLX Lisp library are documented in this file. The project follows
[Semantic Versioning](https://semver.org/).

## [2.0.0] - Unreleased

First public release on Maven Central as `org.fuusio.flx:flx`.

- FLX Lisp parser, evaluator and virtual machine (`FlxVM`) for Kotlin and Android.
- About 350 built-in functions and 44 macros: arithmetic and math, strings, collections and
  sequences, maps, JSON, dates, random numbers, logging, timers and observables.
- Functions, closures, `loop`/`recur`, threading macros, `try`/`catch` and objects.
- No reflection: FLX programs cannot load classes or call Java methods that FLX does not define.

[2.0.0]: https://github.com/Fuusio/flx-lisp/releases/tag/v2.0.0
